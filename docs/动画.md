# 布局与动画

对话区和侧边栏里，什么能让内容换位置、变高矮、改滚动位置。调查和后续计划见 `docs/动画调查.md`。

## 原则

1. **动画必须有，而且要精致**；目标是不出错，不是靠不做动画来避免出错。
2. **动画只做一件事：让变化连续。** 用最简单的过渡，多一种动法就多一种出错的方式。
3. **排版永远是最终的样子。** 没有临时高度；动的只有滚动位置、透明度，和换位时的位移。
4. **能动页面的原因逐条登记**（下表）；没登记的高度变化只保持位置，不做动画。
5. **方向确定**：每个原因只准一个方向，一次移动不掉头。

## 对话在底部时：只动滚动位置（`web/src/chat/stick.tsx`）

行本身不加位移。对话跟随底部靠滚动位置走一根弹簧，所以只会朝底部去。

| 发生了什么 | 怎么处理 | 方向 |
|---|---|---|
| 末尾长出来（新消息、新步骤、草稿、工作块进场） | 滚动位置用弹簧追到底部。自己来的用三倍于一次移动的时间，人的操作用一次移动的时间 | 只向上 |
| 变矮（草稿变正式消息、工作块离场、卡片变短） | 不动。对话下面留同样高的空位；之后长出来的先填空位。回合结束、且 250ms 内没再变时，空位一次收回；不到 32px 的不收 | 回合中不动；结束后向下一次 |
| 人让它变矮（输入框变矮、收起折叠） | 空位立刻收回，对话落下来 | 向下 |
| 自己做高度动画的（折叠的展开收起、回合结束收起过程、长文折叠） | 它自己画；每一帧只把底部贴住，不留空位、不追 | 展开向上，收起向下 |
| 没有盒子的行（`display: none`）、末尾自己的行（`data-tail`：工作中的 agent） | 不当作屏幕顶端那一行：前者位置读出来是 0，后者上面插进回答是末尾在变，都不是“上方变高” | 不动 |
| 屏幕上方的内容变高矮（很上面的卡片晚填、图片晚到） | 滚动位置同时跟着改，屏幕里的不动 | 不动 |
| 窗格本身变高矮（键盘、窗口）；刚打开 600ms 内填进来的 | 直接贴底，不做动画 | 跟随 |
| 人翻上去之后 | 什么都不动；下面来了新内容只亮“新消息”键 | 不动 |
| 往上翻页、补更早的回合 | 画出来的同一帧把滚动位置加回去 | 不动 |

涨和缩相抵：滚动位置还没追完的路程，和留着的空位，哪边有就先互相抵掉，所以先缩后涨、先涨后缩都不会来回。

`layoutMoves(el, ms, to?)`：在高度开始变之前说。说的时候列里还没被看到的高度变化不算它的，按普通变化处理。`to` 是收起到多高，只有给了才在“翻上去一点”时跟着收起带下来；长文折叠不给。

## 其余会动的

| 谁 | 管什么 |
|---|---|
| `moves.ts`（`useMoves`） | 标了 `data-flip` 的行换了顺序：从旧位置滑到新位置（位移）。它和上面的跟随用的是不同的属性，互不等待 |
| `moves.ts`（`useLeaving`）、`motion.css` `g-depart` | 走掉的行：位置当帧让出，内容在原处淡出 |
| `Arrive`、`g-arrive`、`g-fade`、`pushIn` | 进场：只改透明度和几像素的升入，不改大小 |
| `motion.ts` `pageTurn` | 会话之间切换（浏览器的 View Transition） |
| `g-reveal` | 一行自己的展开收起（高度过渡）。对话区里用它的地方列在 `web/test/movers.test.ts` |

## 规范

1. 组件只画最终状态。要让页面动，用上面已有的；不在组件里新写 `animate()`、会改大小的过渡、或改滚动位置。`web/test/movers.test.ts` 列着现有的每一处，新增一处要在那里加一行并写明理由。
2. 晚到的数据先占位：新加一行、一张卡片时，先回答“数据什么时候到、到之前占多高”。
3. 进场、出场只改透明度和不占位的位移。
4. 位移和透明度的动画不加在高度不封顶的元素上（WebKit 按元素大小备绘制缓冲，整列对话滑动时多占过 1.3 GB）；`moves.ts` 只动看得见的部分（`seen.ts`）。
5. 时间只用 `--move`、`--fade`、`--reveal`。新增时间常数要写明它在等什么；用来让两段动画互相让路的不许加。
6. 减少动画（系统设置）时：位置直接到位，只留淡入淡出。

## 移动记录（`web/src/motionlog.ts`）

每次移动记一条：谁、为什么、多少像素。`window.__moves` 可读。原因是 `?` 的，是没有组件声明、只是被发现高度变了的。

## 验收（`web/scripts/motion/scen.mjs`）

按画出来的每一帧，记一行在屏幕上的位置。每个场景：往错的方向走的帧数为 0，掉头次数为 0（回合结束收起过程、收回空位算一次向下）。

场景：agent 回合；发消息；输入框变高、变矮；翻上去时来新内容；回到底部后再一个回合；切走再回来位置不变；自己的 agent 写回合；点开、收起折叠。Chromium 和 WebKit 各跑一遍。

```
sh web/scripts/motion/build.sh <源码目录>   # 构建到 /tmp/irperf/out
sh web/scripts/motion/setup.sh              # 起一个临时实例，建好会话
node web/scripts/motion/scen.mjs chromium   # 或 webkit
```
