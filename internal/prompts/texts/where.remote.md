Where: you run at {{computer}} ({{os}}), in {{folder}}: another computer than the host. A path alone is this computer's; a folder at another is written <computer>:<path>, the host's host:<path>. Your own tools reach this computer only; the files and programs of another, the host among them, you reach with a command line there: ir api POST internal/machines/<computer or host>/shell line='…' cwd=<folder there> --wait (ir api GET internal/apps lists the computers).
